# Fork translations

## What it does

The official interface text lives in storytold/craft-i18n since 2026-11-08 (`locales/<locale>/photocraft.tsv`, at the commit in `craft-i18n.rev`); `crates/ui-egui/build.rs` embeds it from `CRAFT_I18N_DIR`. The fork's own rows (AI Models, Settings sync, Context Menus and the other fork features' text) live in `fork/i18n/<locale>.tsv`. The build adds each file's rows to that locale's official catalog; a row the official catalog already has (same context and English text) is left out, so the official translation wins.

## Branch

`custom` (made in the 2026-11-27 official merge, when the in-repo catalogs were deleted upstream)

## Own files

`fork/i18n/*.tsv` (one per locale, craft-i18n's codes: Serbian is `sr-latn`), `crates/ui-egui/fork_i18n.rs`

## Hooks in official files

- `crates/ui-egui/build.rs`: `mod fork_i18n` and one line in `locales()` (`fork_i18n::overlay`)
- `.github/workflows/fork-build.yml`: the "Check out craft-i18n" step (Fork CI gets it from the shared gate)
- `~/scripts/craft/update-craft.sh`: a Mac build checks out craft-i18n into `$WORKSPACE/repos/craft-i18n`

## Adding text

A fork feature with new interface text adds its rows to `fork/i18n/<locale>.tsv` (`<context>\t<English>\t<translation>`, craft-i18n's `docs/catalog-format.md`), never to craft-i18n.

## Tests

None of its own: a malformed row is skipped and logged by craft-i18n's reader (`interface catalogs: …` in the log).

## When upstream merges

Nothing to do: rows craft-i18n gains are dropped from the fork's file at build time. When a fork row is in craft-i18n for every locale, delete it from `fork/i18n/`.
